# BKPOS v1.0 — Final Release

This is the frozen production baseline following the completed Phase 34
manual workflow acceptance and Phase 37 production controls.

Included: POS, purchasing/GRN, stock/costing, debtors, creditors, VAT/profit,
JasperViewer, central History/reprinting, reports, backup/recovery,
permissions/audit controls, and database initialization/migration support.

The live `pos_store.db` is deliberately excluded. Back up an existing live
database before upgrading. Physical printer acceptance is deferred until the
printer hardware is available.
