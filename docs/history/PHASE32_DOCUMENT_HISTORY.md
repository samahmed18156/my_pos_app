# Phase 32 — Central Document History & JasperViewer Reprint

BKPOS now provides a central **History** option for finalized business documents.

## Included
- Sales invoices
- GRNs
- Customer credit notes / returns
- Supplier credit notes
- Customer receipts
- Supplier payments

## Features
- Date range filtering
- Document-type filtering
- Search by document number/reference/name
- Double-click a document to view it
- **VIEW / REPRINT IN JASPER VIEWER** button
- Uses the selected document's original database ID
- History is read-only; finalized transactions are not edited from this screen

The existing account-management history remains available. Phase 32 adds a central archive/reprint workflow so a customer or supplier document can be found without first opening the account screen.
