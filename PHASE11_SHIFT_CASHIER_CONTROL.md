# Phase 11 — Shift & Cashier Control

Adds a read-only management control center over the existing cashier shift,
sales, void and return records.

## Controls
- Shift-level sales and transaction performance
- Open-shift detection
- Cash variance detection
- Cashier sales, average basket, void and return analysis
- Date-range filtering
- CSV export
- Utility menu integration

No existing checkout, stock, accounting, branch synchronization, promotion,
loyalty or reporting workflow is removed or altered.
