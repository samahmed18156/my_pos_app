BKPOS Phase 77
Real-Shop Workflow Readiness

This development release strengthens the final operator workflow before the Gold Release.
It includes a read-only shop smoke gate and critical regression coverage for opening shifts,
cash controls, GRNs, sales, returns, receipt-printer failure handling, day-end recovery,
and upgrade/uninstall data protection.

Live installed BKPOS and the live user database are never included or modified by the release process.
