generated, build, and IDE artifacts. The source tree is safe to use as the
master PyCharm project and as the input to the Windows packaging scripts.

JASPER RUNTIME
jasper_runtime/ is intentionally retained because the Windows PyInstaller
spec packages these JasperReports dependencies into the BKPOS application.
It is not user data and is required for JasperViewer/report functionality.

INSTALLED APP DATA
Packaged BKPOS stores live writable data under %APPDATA%\BKPOS.
The PyCharm source project's database is not the installed application's live database.
The installed application itself is under %LOCALAPPDATA%\BKPOS.
